1.4.2
- Fixed calendar month reset — January (month 0) was treated as falsy, causing the calendar to snap back to the current month on every render.
- Fixed calendar view persistence — switching to calendar view was lost on page reload because the view-mode restore only checked for 'grid' or 'list'.
- Added missing -webkit-backdrop-filter vendor prefix on four elements (price badge, modal, side nav, stats panel) for Safari compatibility.
- Fixed unhandled promise rejection in Dropbox auto-sync — dropboxDownload call was not awaited inside dropboxCheckForUpdates, risking a crash if the token refresh endpoint returned non-JSON.
- Fixed fragile e.target reference in archived-game restore handler — now uses e.currentTarget via the button reference.
- Added null guard to positionSideNav and positionStatsPanel to prevent crash if #wrap is absent.
- Eliminated redundant double render() call at startup — chip colour initialisation no longer triggers a separate full re-render.
